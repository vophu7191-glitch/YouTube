# Jion – Privacy Policy

_Last updated: 16 November 2026_

## 1. About Jion

Jion is intended to connect Discord communities with public YouTube channel and livestream information. Depending on the features enabled, it may help server administrators maintain membership-related features, link a member's Discord identity with a YouTube channel, monitor public livestreams, and post livestream notifications.

## 2. Information Jion may process

Depending on configuration and the permissions granted, Jion may process:

- Discord user IDs and server IDs.
- Basic server membership information needed for membership-related features.
- Current Discord presence status (Online, Idle, Do Not Disturb, or Offline/Invisible) only if the Presence Intent is enabled. Jion keeps the current status in bot memory for display and does not write presence status or status history to its database. The user's opt-out preference is stored in the database.
- YouTube channel IDs, public channel information, livestream titles, livestream URLs, and public livestream status.
- Discord-to-YouTube account-link records created by a user or server administrator.
- OAuth tokens or authorization records, if the application uses Google OAuth. These must be stored securely and used only for the scopes the user approved.
- Basic technical and diagnostic logs needed to operate and secure the service.

Jion should not request or store Discord, Google, or YouTube account passwords.

## 3. How information is used

Information is used only as needed to provide and maintain the features, such as:

- Displaying relevant server membership information and, when enabled, showing current Discord presence beside member names in the private `/trang-thai` response.
- Associating a Discord member with a YouTube channel when that link is intentionally created.
- Checking public YouTube livestream information.
- Sending configured notifications about new or active livestreams.
- Troubleshooting errors, preventing abuse, and protecting the service.

## 4. Private communications and sensitive information

Jion is not designed to read Discord direct messages or private conversations. It should not collect passwords or unrelated private content. The application must not use an available permission or technical capability for a purpose that has not been disclosed to users.

## 5. YouTube and Google services

If Jion uses Google OAuth or YouTube API Services, access is limited to the scopes and permissions shown during Google's authorization flow. Users should review those permissions before approving them and can revoke access through their Google Account security settings.

Jion's use of YouTube API Services is subject to the applicable Google and YouTube terms and policies, including the YouTube API Services Terms of Service and Google Privacy Policy.

## 6. Sharing

Jion does not sell personal information. Information may be processed by infrastructure or service providers strictly as needed to host, secure, and operate Jion, or disclosed where legally required. Any provider access should be limited to the service it performs.

## 7. Retention and deletion

Jion keeps current Presence values in temporary bot memory and does not persist Presence status or status history in its database. A user's Presence opt-out preference is stored so the choice remains effective after a restart. Jion should retain other personal information only for as long as it is needed for the disclosed feature, security, or legal obligations. When a Discord-to-YouTube link is removed, the associated link data and OAuth credentials should be deleted or invalidated when no longer needed.

Users can opt out of Presence display in each server with `/presence-opt-out` and opt back in with `/presence-opt-in`. The opt-out preference can be removed by opting back in. To request access to or deletion of other information, contact **vophu7191@gmail.com**. Users can also revoke Google authorization through their Google Account settings. Revoking authorization may stop YouTube-linked features from working.

## 8. Security

Reasonable technical and organizational safeguards should be used to protect stored information, including access controls and secure handling of credentials and OAuth tokens. No online service can guarantee absolute security.

## 9. Children's privacy

Jion is not intended to override age requirements or other rules imposed by Discord, Google, or YouTube. Users must meet the applicable platform age requirements.
