1. About Jion

Jion is an application that integrates Discord and YouTube. It is intended to support necessary member-related features, link Discord members with YouTube channels, and monitor public livestream information for configured notifications.

2. Information Jion may process

  • Discord user IDs and Discord server IDs.
  • Basic server membership information needed for member-related features.
  • Current Discord presence status (Online, Idle, Do Not Disturb, or Offline/Invisible), only when the Presence Intent is enabled. Jion temporarily keeps the current status in the bot's memory for display and does not write presence status or status history to its database. The user's Presence opt-out preference is stored in the database.
  • YouTube channel IDs, public channel information, and public livestream data such as titles, URLs, and live status.
  • Discord–YouTube linking records created by a user or server administrator.
  • OAuth authorization information and tokens, if Jion actually uses Google OAuth. These must be protected and used only for the scopes granted by the user.
  • Limited technical logs needed to operate, secure, and troubleshoot the service.

3. How information is used

  • To support member-list features and, when enabled, display current Discord presence beside member names in the private response to the /trang-thai command.
  • To link a Discord member with a YouTube channel when intentionally configured by the user or an authorized administrator.
  • To check public YouTube livestream information.
  • To send livestream notifications configured by a server.
  • To maintain, secure, and troubleshoot the service.

4. Direct messages and sensitive information

Jion is not designed to read Discord direct messages or private conversations. Jion does not request Discord, Google, or YouTube account passwords. The application must use access only for the purposes disclosed in this policy and permitted by the relevant authorization.

5. Google OAuth and YouTube

If Jion uses Google OAuth or YouTube API Services, access must be limited to the scopes explained in the authorization screen. Users can review and revoke granted access in their Google Account security settings. Jion's use of YouTube data must comply with the applicable Google and YouTube terms and policies.

6. Sharing information

Jion does not sell personal information. Information may be processed by infrastructure providers where necessary to host, secure, and operate the service, or disclosed where legally required. Provider access should be limited to the services they perform.

7. Retention and deletion

Current Presence status is kept temporarily in the bot's memory and is not stored in the database; Jion does not retain a history of presence changes. A user's Presence opt-out preference is stored so that the choice remains in effect after the bot restarts. Other information should be retained only as long as necessary for the stated purpose or legal obligations. When an account link is removed, associated linking data and OAuth credentials that are no longer needed should be deleted or invalidated.

Users can use /presence-opt-out in a server to opt out of Presence display and /presence-opt-in to opt back in. The opt-out preference is removed when the user opts back in. Requests to access or delete other information can be sent to vophu7191@gmail.com. Users can also revoke Google access through their Google Account.

8. Security

The operator should use appropriate technical and organizational safeguards, such as access controls and secure handling of credentials. No online service can guarantee absolute security.

9. Age requirements

Users must meet the applicable age requirements and terms of Discord, Google, and YouTube. This policy does not replace those requirements.

This policy may be updated when Jion's features, data practices, or legal requirements change. The latest version will be published on this page.
